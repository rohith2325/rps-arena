🎮 RPS Arena – Rock Paper Scissors

A modern, interactive Rock Paper Scissors game built using HTML, CSS and JavaScript.

🌐 Live Demo

"Play RPS Arena" (https://rohith2325.github.io/rps-arena/)

✨ Features

- 🎯 Classic Rock Paper Scissors gameplay
- 🤖 Three difficulty levels: Easy, Medium and Hard
- 🏆 Best of 5 match system
- 📊 Live scoreboard and match statistics
- 🔥 Win streak tracking
- 🥇 Leaderboard
- 👤 Custom player profile
- 🎉 Confetti celebration when winning
- 🔊 Sound effects
- 🎵 Looping background music with ON/OFF control
- 📜 Recent match history
- 💾 Local storage to save player statistics
- 📱 Responsive gaming interface

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- Web Audio API

🎮 How to Play

1. Open the game using the Live Demo link.
2. Choose your difficulty level.
3. Select Rock, Paper or Scissors.
4. Try to defeat the computer.
5. First player to win 3 rounds wins the match.
6. Track your statistics and leaderboard position.

🚀 Run Locally

1. Clone this repository:

git clone https://github.com/rohith2325/rps-arena.git

2. Open the project folder.
3. Open "index.html" in your browser.
